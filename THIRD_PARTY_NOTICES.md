# Third-party notices

## Code

The game rules, rendering, effects and sound are written for this project. [Vite](https://vitejs.dev) (MIT) is used only as a build tool and is not included in the built site.

- [PeerJS](https://github.com/peers/peerjs) 1.5.5 (MIT, Copyright (c) 2015 Michelle Bu and Eric Zhang) is bundled for online lobbies. It is only loaded when a player opens a lobby. Lobbies use the free public PeerJS signalling server (0.peerjs.com) to introduce players; game traffic then goes directly between browsers.
